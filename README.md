# Node Rogue · 节点肉鸽

A VFX survival roguelite in pixel art. You were laid off when your studio closed. Twelve weeks of savings, a landlord who likes rent more than you, a cat, and one dream studio.

特效师求生像素肉鸽。工作室倒闭，你被裁了。十二周存款，一个更爱房租的房东，一只猫，一家梦想公司。

**Play / 试玩：** https://kurtliu309.github.io/vfx-rogue/ （或双击 `index.html`，无需服务器）

## 一局怎么走

- 12 周三幕。每周：周一看邮件（剧情 + 随机事件选择）→ 接活板**只选一个**：零活（付钱）/ 作品集镜头（不付钱，进 reel）/ 工作室测试（第 4、8、12 周）→ 搭节点网络 → Cook（dailies）→ 交付 → 周末交房租、逛商店。
- 交不起房租 = 被赶出门。第 4 周 Kiln & Co、第 8 周 Northlight 给 offer，可接受（结局）或拒绝（得遗物“底气”）继续冲第 12 周 Halcyon。
- 结局 5 种：被赶出门 / 安稳港湾（Kiln）/ 两季合约（Northlight）/ 依然自由 / Halcyon（梦想）。结局播放整条 reel。

## 核心机制

- **网格自动连线**：数据从左往右流，空格是导线，每行右端进 OUT，镜头取最好的一行。Merge 收左、左上、左下。
- **主角元素 ★ 深度**：火 / 水 / 破碎 / 生物 / 魔法，各有 4 步依赖链（例：Pyro Source → Pyro Solver → Turbulence → Upres）。每步 +★1；质量档、解算细节、Fire Light、Heat Haze、专精遗物再加。缺上一步就像 Houdini 一样报红错。
- **管线上限**：没打光最高 ★2（playblast），没合成 ★3.5，成片 ★5。基础灯光、基础合成就够——专精一条链，其他部门用便宜节点凑。
- **Brief = 清单**：主角 ★ 门槛 + 过/不过的要求（有材质、夜景、合进实拍、颗粒、烟尘、风格化、有环境、打磨 ≥ N…）。
- **评级**：`pts = (★ − 门槛) × 2 + 有效打磨`；B / A / S = 3 / 6.5 / 8.5 分，报酬倍率 C 0.85 / B 1.1 / A 1.5 / S 2.1。**同一种打磨来源只计一次**（两个 Grade 只算一个 Grade），质量档打磨按节点计；打磨超过 3 点后对评级边际减半（仍可满足“打磨 ≥ N”）。
- **环境**：Terrain 直接当主行的源**不算**“有环境”，必须另起一行再用 Merge 并进取分的那一行。环境 + 实拍同时出现时需要 3 行（主行在中间）。
- **Dailies + 缓存**：每次 Cook 是一轮 dailies，客户回 note。没改动的节点走缓存 0 工时。6 种客户性格各有一条会改决策的 note：好说话（第一次 dailies 后**直接交付** +20%，再 Cook 就失去）/ 永远要更大（门槛 +1★）/ 改主角元素（报酬 ×1.6，只换到你牌组**真能交付**的元素；一个都不行就保持原要求，只抱怨一句）/ 隐藏要求（只从牌组能满足的要求里抽）/ 完美主义（打磨 +1 且门槛 +0.5★，测试关不下狠手）/ 时间紧（**接活看到 brief 时**就二选一：剩余工时 −10%，或报酬 ×0.8 保住工时）。
- **实时解算**：Solver 在 Cook 时逐帧跑，细节和不稳定度一起涨。界面只给**稳 / 警告 / 危险**三档（没有精确百分比），而且每把解算的档位边界会随机偏移 ±20；粒子抖动、画面偏色随档位变化。尖峰概率随帧数递增（`0.03 + 0.004·f`），细节增长到后期衰减，所以“固定第 N 帧收手”或“见到危险就停”都只是经验，不是标准答案——即使最好的三档规则也比全知最优低 17% 左右。Wedge 遗物显示预测发散帧（±3 帧误差）。旁边放 Collision 更稳；Roto Rescue 能救回低一档。发散的解算下次 Cook 自动重解。
- **质量档 Q1–Q3**：风险/回报，不是悬崖。更多星/打磨（Q2 +0.5★ +0.5 打磨，Q3 +1★ +1 打磨）、更多工时和内存。失败时节点功能保留：主角链节点仍然算到这一步但 −0.5★；配套/灯光/合成节点不拿质量打磨并 −1 打磨（最低 0）。解算器永远零风险，质量档只加快细节增长。
- **硬件与资源**：CPU = 列数（5→8），GPU = 行数（2→4），内存 = 每列能放多重（超了 OOM 不能 Cook）。FLIP / Upres / Mesher 等重 FX 基础内存 16–18，Q2 ×1.5、Q3 ×2。工时不够可花钱租渲染农场。
- **商店**：在线课程（新节点）、遗物（软件与习惯，含 HDA）、硬件（GPU $320/$480、内存 $160）、练习（精通节点 −1h 风险减半）、咖啡、HDA 打包（两个节点合一格）。每周固定有一门课是你还缺的要求 enabler（月灯 / 镜头颗粒 / 卡通 / 实拍合成 / 地形 / 烟尘层），带“unlocks: 夜景”这类标签。HDA 在第 3 周后的商店里保证至少出现一次。遗物只卖你自己元素的 `nerd_*`；农场半价且每次 +2h，咖啡因 +5h +1 次 dailies，备份硬盘每个活多一次质量档失败保护，作品集网站给测试镜头 +3 打磨。
- **开局身份**：Pyro TD / 驯水师 / 生物艺术家 / 多面手。接活板每周至少一个活对口你的专长，而且**对口那个活的额外要求一定是你当前牌组能满足的**；但它不等于保送——它可能把星级门槛定得比你现在的牌组高（约 5% 的周三个活全接不了）。其他活不保证——看到做不了的活，就知道该买什么。四个开局有各自的起始资金（$300–$1000），用来抵消专精链的成本差。
- **Dust Pass / 烟尘层**：1h / 2 内存的通用 FX 节点，接任何模型或解算流都能满足“烟尘”，不加主角星。它在商店保底 enabler 池里。
- **收尾路线不止一条**：扫描模型自带材质并省一个材质格；Upres / Mesher 只要 2h，第 4 步链真的排得进工时；Fire Light 给火系 +2 打磨，Heat Haze 是带打磨的火系成片，Glow 让魔法第 4 步再 +0.5★，Path Tracer 任何元素 +2 打磨（4h），Roto 救场 1h / +1 打磨且能救发散的解算。

## 数值在哪改

`engine.js` 顶部 `CONFIG`：存款、房租、工时、dailies 次数、硬件上限和价格、风险、管线上限、评级门槛和倍率、解算参数、商店价格。节点在 `def(...)` 一节，遗物在 `RELICS`，开局身份在 `BACKGROUNDS`。客户、工作室门槛、剧情和事件在 `story.js`。

## 语言

默认英文，右上角 `中文 / EN` 即时切换，存在 `localStorage`（`vfxRogue.lang`）。新增界面文字要同时写进 `i18n.js` 的 en 和 zh；数据文字用 `loc(en, zh)`。进度存在 `vfxRogue.v2.save`（每周开始的邮件阶段不存档）。
